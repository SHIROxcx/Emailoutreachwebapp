Sending Windows

Auto-pauses campaign after 3 consecutive errors to protect your sender domain reputation.

04
Phase 4 Sequence Studio
Completed

Campaign Studio, Spintax Permutations & Cascade Delete Fix

🔴 The Problem: Deleting campaigns was throwing server errors due to locked database foreign keys. Also, cold emails sound spammy and trigger filters when every recipient receives identical text.
🟢 What We Did: Fixed campaign deletion using transactional cascade cleanup. Built a multi-step sequence builder with delay offsets and a recursive Spintax engine (e.g. {Hi|Hello|Hey}) with variable fallbacks ({{firstName|there}}) and a live interactive Spintax Preview modal.
💡 Why It Matters: Every email sent is linguistically unique, preventing spam filter pattern detection. Campaigns can be deleted cleanly without database locks.

Core files: src/lib/campaigns/spintax.ts, src/app/api/campaigns/[id]/route.ts, src/components/campaigns/SpintaxPreviewModal.tsx

// Recursive Spintax Permutation Parser
export function parseSpintax(text: string): string {
  const pattern = /\{([^{}]+)\}/g;
  while (pattern.test(text)) {
    text = text.replace(pattern, (_, choices) => {
      const parts = choices.split('|');
      return parts[Math.floor(Math.random() * parts.length)];
    });
  }
  return text;
}

06
Phase 6 Safety Guardrails
Zero-Accident Design

Multi-Layer Campaign Execution Safety Guardrails

🔴 The Problem: Sending cold email carries severe risks: sending during the middle of the night, blasting 1,000 emails at once, hitting unsubscribed contacts, or continuing to send after mailboxes get flagged.
🟢 What We Did: Implemented a 5-layer defense architecture:
  • Pre-Flight Audit Checklist: Blocks campaign activation until 6 criteria pass (mailbox, sequence, leads, syntax, quota, schedule).
  • Dual Quota Limits: Daily cap for mailbox (50) and campaign (30).
  • Business Hours Windows: Only sends between 09:00 - 17:00 in target timezone (Mon-Fri).
  • Automated Circuit Breaker: Auto-pauses after 3 consecutive failures.
  • Global Emergency Stop: Red kill-switch button visible everywhere to halt all sends instantly.
💡 Why It Matters: Makes human error practically impossible and keeps your sender domain off email blacklists.
Before Unchecked campaigns could blast hundreds of emails at 3 AM or repeatedly fail on invalid emails.
After Automated pre-flight modal, strict business hours, dual daily quotas, circuit breaker auto-pause, and global kill switch.

Core files: src/lib/worker/dispatcher.ts, src/app/api/campaigns/[id]/audit/route.ts, src/app/api/campaigns/emergency-stop/route.ts, src/components/campaigns/CampaignLaunchGuardModal.tsx

// Automated Circuit Breaker & Pre-Flight Check in dispatcher.ts
if (consecutiveFailures >= 3) {
  await prisma.campaign.update({
    where: { id: campaign.id },
    data: { status: 'PAUSED', pauseReason: 'CIRCUIT_BREAKER_TRIGGERED: 3 consecutive failures' }
  });
}

The Autonomous Background Sending Engine (BullMQ + Redis)

🔴 The Problem: Cold outreach should run hands-free. Having to keep a browser tab open or manually click "Send" is fragile and impractical.
🟢 What We Did: Built a production-grade background worker daemon using BullMQ and Redis. Registered recurring job schedulers that wake up every 5 minutes to process due emails and reset quotas at midnight UTC.
💡 Why It Matters: The engine runs continuously as a background service. You can close your browser, turn off your laptop, and the scheduler keeps executing safely.

Core files: src/lib/worker/queue.ts, scripts/run-worker.ts, package.json

// Run the standalone daemon
npm run worker

// BullMQ v6 Repeatable Job Registration

await outreachQueue.upsertJobScheduler('midnight-quota-reset', { pattern: '0 0 * * *' });

How To Use The Application (1-Minute Quick Start)

Step 1: Start Infrastructure

Make sure Docker is running, then verify PostgreSQL and Redis:

docker start outreach-postgres outreach-redis
Step 2: Start Web Server

Run the Next.js frontend and API server:

npm run dev

Open http://localhost:3000 in your browser.

Step 3: Generate Demo Leads

Navigate to Leads in the top navigation, and click the blue "Generate Demo Leads" button to load 15 rich test prospects.

Step 4: Launch Background Engine

In a separate terminal, launch the autonomous worker daemon:

npm run worker
